# Data folder

Large datasets are not shipped in the ZIP. Put the source file here:

    data/raw/food_quality_master_expanded_transparent.csv      (36,789 rows, 28 columns; the latest/superset file)

(`food_quality_demo_training_data.csv` is a strict subset of it and is optional; it is only read by
`inspect_dataset` to confirm that.) `data/prepared/` is generated by `python -m src.prepare_dataset`.
Source files are never modified.

Required columns: sample_id, data_origin, is_synthetic, is_sensor_value_real, food_type, food_category,
specimen_uid, training_split_group, storage_day, MQ3_raw, MQ135_raw, temperature_C, humidity_pct,
freshness_label, label_method, demo_training_candidate, is_saturated, quality_tier.
